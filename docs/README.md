# API de Laboratório de Ensaios

Estrutura base da API para gerenciamento de analistas, ensaios e equipamentos.

## Rotas principais

- GET /health
- GET /api/analistas
- GET /api/ensaios
- GET /api/equipamentos

## Variáveis de ambiente

Copie o arquivo `.env.example` para `.env` e ajuste as configurações do banco de dados.
